# 命题对齐说明

官方命题要求构建设备与质量知识底座，以 Graph RAG、Autonomous Agent 等方式主动捕捉异常，输出可解释证据链和处置方案，并结合飞书 Aily、多维表格实现任务协同。

| 官方命题要点 | 仓库实现 | 当前边界 |
|---|---|---|
| 本体论与知识图谱 | 设备、工位、质量特性、失效模式、原因、验证动作和责任角色的节点与关系 | 使用合成知识条目，不代表企业正式本体 |
| 主动捕捉异常 | 数字员工读取事件后调用 SPC 与设备信号工具，不等待用户提问 | MVP 使用离线事件重放，未接实时消息总线 |
| Graph RAG | 以异常对象为起点检索相关子图、PFMEA、控制计划和历史案例 | 当前推理器确定性可复现，未调用外部大模型 |
| Autonomous Agent | 感知、检测、检索、研判、行动五步工具轨迹 | 不允许自动停线、改参数或确认根因 |
| 可解释证据链 | 每条证据包含类别、观察、来源、定位、强度和数据 | 企业接入后需增加文档版本与权限字段 |
| 处置方案 | 候选原因、验证步骤、责任角色、时限和验收依据 | 建议需工程师确认 |
| 飞书协同 | 生成风险主表和任务子表字段预览 | 未配置企业应用凭证，不发送网络请求 |
| 从感知到行动 | 风险卡进入人工审批、点检、抽检、追溯和结案流程 | 结案回写在演示中以数据结构表示 |

本项目把“自主”限定在持续观察、发起分析、调用工具和追踪待办。停线、参数修改、批次隔离等影响安全或生产的动作仍由授权人员决定。

官方命题来源：[赛力斯集团命题详情页](https://activity.feishu.cn/future-talent?detail=sailisijituan)。
