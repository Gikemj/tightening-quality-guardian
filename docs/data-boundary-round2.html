可以使用

对象、字段和关系设计

对象定义

  • 设备类别、设备实例、设备功能、失效模式和故障工单的字段角色。

关系约束

  • 设备类别 → 设备实例 → 故障工单 → 失效模式 → 设备功能 → 设备类别。

闭环设计

  • 关系完整性、人工核验、任务协同和经审核后的知识更新。

不使用

不把脱敏包当作真实生产数据

不做知识抽取

  • 不从受控类别和脱敏关联中生成企业知识结论。

不做时序分析

  • 数据不含可用于工艺趋势、设备健康或节拍判断的真实时间序列。

不做企业效果测算

  • 不以公开演示案例计算产线准确率、停机损失或投资回报。
