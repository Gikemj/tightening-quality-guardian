# 方案决策记录

## ADR-001：先做一个拧紧工位

决定：MVP 只覆盖总装关键拧紧工位。

理由：设备参数与产品质量关系明确，数据可合成，能够同时验证 SPC、PFMEA、知识图谱和任务闭环。若同时覆盖冲压、焊装、涂装和总装，只能停留在概念层。

## ADR-002：风险是候选结论，不是自动根因

决定：输出候选原因、置信度和验证方法，根因由工程师确认。

理由：设备、材料、工艺和量测信号可能相关，但现场因果需要额外检查。公开原型也没有足够数据做确定性判断。

## ADR-003：确定性推理优先

决定：公开 MVP 使用透明规则和图检索，不依赖外部大模型。

理由：评委可以复现每个数字和来源；代码不需要 API 密钥。进入企业带教后，可把受控生成模型接到同一证据结构上。

## ADR-004：飞书只做字段预览

决定：公开演示不发送外部请求。

理由：真实字段 ID、权限和审批策略应由企业提供。公开仓库不保存凭证，也不应制造“已经接入企业系统”的误解。
