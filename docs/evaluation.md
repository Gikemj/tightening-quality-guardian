# 离线验证说明

## 目标

当前验证只回答两个问题：合成的规格内漂移场景能否被识别；每次识别能否生成可追溯证据和完整任务字段。它不证明真实工厂的泛化效果。

## 数据与标签

数据生成脚本使用固定随机种子 `20260717`，共生成 820 条记录。P03 最后 36 条被标为 `hidden_risk`，注入扭矩缓慢上移、角度离散增大、重试增加、电流和节拍轻微变化。扭矩仍控制在 43–53 N·m 规格内。

验证从第 124 条 P03 记录开始，每隔 2 条形成一个滚动样本，共 49 个窗口。最近 24 条中含 `hidden_risk` 即为正样本。风险等级为中或高视为系统提示。

## 当前结果

混淆矩阵：TP 17、FP 1、TN 30、FN 1。

| 指标 | 结果 | 计算 |
|---|---:|---|
| 召回率 | 94.4% | TP / (TP + FN) |
| 精确率 | 94.4% | TP / (TP + FP) |
| 误报率 | 3.2% | FP / (FP + TN) |
| 证据可追溯率 | 100% | 同时具有来源和定位的证据 / 全部证据 |
| 任务字段完整率 | 100% | 同时具有责任人、时限和验收依据的任务 / 全部任务 |

## 如何复现

```bash
PYTHONPATH=src python3 scripts/generate_demo_data.py
PYTHONPATH=src python3 scripts/build_demo_assets.py
PYTHONPATH=src python3 scripts/evaluate.py
```

结果写入 `outputs/metrics.json`。CI 会重新生成数据和产物，并检查提交内容与脚本输出一致。

## 限制

- 合成标签由注入逻辑产生，难度低于真实现场；
- 只有一个主工具、一个车型和一个程序；
- 没有覆盖维修后基线重建、传感器故障和长期季节性变化；
- 当前阈值未按真实误报成本优化；
- 未与人工工程师做盲测时间对照。

进入企业试点后，首批指标应包括异常召回率、误报率、从信号出现到工程师介入的时间中位数、证据完整率和结案记录完整率。业务收益应在对照试点后计算，不能在海选阶段先写结论。
