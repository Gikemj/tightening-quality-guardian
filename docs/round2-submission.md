# 质控前哨：总装拧紧设备质量风险主动管控原型

队伍：智造哨兵　　企业命题：赛力斯集团

> 如果你加入赛力斯超级工厂团队，你如何打造一名会主动管控设备质量风险的 AI 数字员工？

## 项目概述

质控前哨面向总装关键拧紧工位，先发现“规格内但过程正在变差”的设备与质量风险，再将证据整理成工程师可审核的风险卡和任务草案。当前版本把范围收在一个模拟工位 ST-FAS-07、一个工具 TQ-17 和一个紧固点 P03，保证每个指标都能回到数据窗口，每项建议都有来源和验收条件。

页面和仓库中的设备、工艺、质量与历史案例均为比赛合成数据，不代表赛力斯内部记录。系统不会自动停线、修改 PLC、判断质量放行或确认根因。

## 一、业务问题

关键拧紧连接的风险不一定从“越过规格”开始。工具标定临近到期、套筒磨损、连接件摩擦变化，都可能先表现为扭矩中心缓慢偏移、角度离散增大或重试次数上升。若只等报警码或规格越限，设备工程师、工艺工程师和质量工程师往往还要在多份曲线、台账和知识文件之间手工拼接证据。

本项目将这条链路固定为：

```text
拧紧事件与设备信号
        ↓
同口径基线 / 最近窗口 / SPC 规则
        ↓
设备、PFMEA、控制计划与历史案例的证据关联
        ↓
风险卡、候选原因与验证动作
        ↓
具名审批、任务、现场验证与结案审计
```

## 二、主演示场景

P03 最近 24 次拧紧的扭矩仍在 43–53 N·m 规格内，但相较同车型、同工位的 100 次基线窗口出现以下变化：

| 信号 | 基线 | 最近窗口 | 页面用途 |
| --- | ---: | ---: | --- |
| 扭矩均值偏移 | 0.00σ | +1.56σ | 判断中心是否漂移 |
| 角度离散度 | 1.00× | 2.17× | 判断过程离散是否扩大 |
| 重试均值 | 0.010 次/循环 | 0.250 次/循环 | 判断设备侧摩擦或工具状态变化 |
| 规格内比例 | 99.0% | 95.8% | 与趋势一起解释，不单独下结论 |

三个信号同向变化时，系统将窗口排在“优先核对”，并生成风险卡 `RC-P03-001`。这里的风险分数只用于处理顺序，不替代正式 PFMEA 的 S/O/D 或 RPN。

## 三、产品如何工作

### 1. 主动感知

系统按车型、工位、工具和紧固点分层建立基线，再对照最近窗口。扭矩、角度、重试、节拍、电流和标定状态进入同一分析上下文。公开页面的“开始工位回放”按钮会先展示 ST-FAS-07、TQ-17 和 P03 的工程示意，再在浏览器中回放确定性合成数据；指标、风险卡和分析轨迹会随批次变化。

### 2. 受约束研判

系统保留三种信息层级：

- **观察事实：**量测值、窗口范围、规则命中、设备状态和文档定位；
- **候选原因：**标定漂移、套筒磨损、连接件摩擦变化等待验证假设；
- **工程决定：**点检、抽检、批次追溯和是否结案，只能由具名工程师确认。

候选原因必须引用已加载的证据，并配有下一步核验方法。证据不足时，页面显示“待补证”，不会用模型补造现场事实。

### 3. 知识与证据链

从 P03 和工具对象出发，系统只取回当前风险所需的有限关系子图，再引用匹配的 PFMEA、控制计划、报警字典和历史案例。每条证据保留 ID、类别、版本指纹、来源定位和强度。关系链的作用是缩小核对范围，不把历史关联写成这一次的根因。

### 4. 人工工作流

管理员工作台直接显示风险、证据、知识修订、接口契约和操作审计。工作流状态由状态机校验：

```text
待工程师审批 → 已审批 → 任务已创建 → 验证中 → 已验证 → 已结案
       ↘ 驳回 / 重新提交        ↘ 验证失败回到任务
```

审批前不能创建任务；验证通过必须提交现场证据；结案需要责任人和依据。公开页面只改变当前浏览器中的预览状态，不向真实飞书租户写入。

## 四、AI 与飞书的使用边界

受控文书模型接口保留在服务端适配器中，当前本地配置为 Hetune 的 OpenAI 兼容接口与 `gpt-5.6-sol`。企业部署时只发送最小化、脱敏的风险卡摘要，限制单次调用、低随机性、固定 JSON 字段和超时回退。输出必须经过 Schema 与安全标志校验，不能确认根因、质量放行、停线或修改 PLC。

公开 GitHub Pages 不加载 API 密钥。没有服务端凭证或模型输出不符合契约时，管理员页面使用同一套确定性规则摘要，因此评委无需登录、安装或启动服务也能验收完整流程。

飞书适配器同时提供“预览”和“经授权 live”两种模式。当前公开演示只展示字段映射和浏览器审计；真实租户的身份、字段、权限和审批联调需要企业授权后单独验证。

## 五、可核验数据与评测

- P03 主演示序列：820 条确定性合成记录，展示规格内漂移的连续回放；
- 独立场景套件：正常、规格内漂移、传感器零漂、重复报警各 30 例；
- 三类异常 90 例的预设场景召回率为 100%，正常场景 30 例误报率为 0%；
- 结果只验证生成器覆盖的代码行为，不能外推为真实产线准确率、提前量或 ROI；
- 传统报警代理仅检查已有报警码或非 `OK` 结果，不代表赛力斯现有系统实测表现。

进入企业带教后，建议先静默运行 2–4 周，再进行 4 周受控对照。验收指标包括风险卡补证率、任务字段完整率、审批退回原因、验证证据完整率和结案记录完整率，之后再评估处理时长与可归因收益。
