# 安全与权限边界

## 当前可执行能力

- 在本地读取比赛合成事件，运行 SPC、设备信号和有限知识关系检索；
- 使用默认确定性研判器生成带证据引用的候选原因；
- 证据不足时拒绝形成候选归因；
- 在真实 Python 调用边界记录输入/输出摘要、耗时、成功/失败和错误；
- 通过本地状态机校验审批、建任务、验证、结案与重开的合法顺序；
- 默认生成飞书字段预览；在显式 live 模式、配置完整、风险卡校验通过，且批准凭证与风险卡工作流中的真实具名批准事件逐字段一致后，代码才允许调用多维表格风险表和任务表接口。

最后一项只是客户端代码能力。仓库没有授权飞书租户联调证据，公开演示不会发送网络请求。

## 系统不能做什么

- 未经批准停止产线、隔离车辆、返工或释放产品；
- 写入 PLC、拧紧控制器或修改工艺参数；
- 根据单次相关性、历史类比或模型文本确认根因；
- 自动改写正式 PFMEA 的严重度、发生度、探测度或 RPN；
- 把未脱敏的 VIN、人员信息或企业文档发送给外部模型；
- 在证据缺失时生成看似确定的处置结论；
- 把可选外部模型接口表述为已经发生真实 LLM/Graph RAG 调用；
- 把 live 客户端或假传输测试表述为已完成飞书/Aily 企业闭环；
- 把合成评测或试点目标表述为真实企业收益。

## 推理失效保护

默认研判不依赖外部模型。外部模型只有在显式配置、密钥和客户端齐备时才进入尝试路径，输出仍必须满足：

- 结论与每个候选原因引用输入中存在的 `evidence_id`；
- JSON 结构符合版本化 Schema；
- `requires_human_approval=true`；
- `automatic_action_allowed=false`；
- 不包含自动停线、改参数、无需验证或“已确认根因”等越权断言。

证据不足时拒答；外部条件缺失或输出不安全时回退到确定性研判。公开演示的 `reasoner_mode` 为 `deterministic`，没有真实外部模型调用。

## 工作流门禁

本地状态机要求：

- 审批/驳回必须由具名操作者执行并填写依据；
- 未批准不能创建任务；
- 创建任务必须提供任务 ID；
- 验证通过必须提供现场证据 ID；
- 结案必须填写说明；
- 非法越级抛出错误，不静默跳转。

状态机验证的是代码合同。当前没有企业身份认证、飞书审批记录或真实结案持久化，不能据此声称现场流程已完成。

## 飞书 live 保护与剩余风险

- preview 是默认模式，不读凭证、不联网；
- live 必须显式选择，并从进程环境读取全部必需配置；
- 缺少配置、风险卡合法状态、真实批准事件、匹配凭证、批准人或批准依据时失败关闭；
- live 运行副本默认写入已忽略的 `.local/live/`，不得复制到公开 `outputs/` 或 `docs/data/`；
- 写权限只应授予试点风险表和任务表，不授予 PLC 或设备控制；
- 仓库和日志不得保存应用密钥或租户 Token。

当前仍缺少跨表事务、幂等键、企业身份校验、审批 API、部分失败补偿、结案/案例回写和授权租户实测。live 模式只应在隔离的授权测试表中验证，详细清单见 [`feishu-integration.md`](feishu-integration.md)。

## 审计边界

每次 Agent 运行会把调用轨迹、研判来源和工作流快照写入风险卡。轨迹来自真实调用边界，而非固定说明文字。

但当前 JSON 产物可以被拥有文件写权限的人修改，不具备防篡改签名、集中保留、企业访问控制或审计告警。真实部署需要将原始事件摘要、规则/知识/Prompt/Schema 版本、调用记录、审批记录、接口结果和结案依据写入受控审计系统。

当前风险卡已落地规则版本、规范化知识语义 SHA-256、规范化输入窗口 SHA-256 和卡片身份 SHA-256；它们能发现重建口径或内容语义变化并帮助复现，但没有密钥签名，不能证明文件未被有权限的人整体替换。

## 数据与价值边界

所有公开数据均为合成数据，不包含赛力斯内部工艺参数、VIN 或人员数据。49 个滚动窗口高度重叠；120 个独立案例也来自预设生成器。它们不能用于训练生产模型、推断工厂能力或计算企业收益。

真实效果必须通过企业批准的静默与对照试点验证，见 [`pilot-plan.md`](pilot-plan.md) 和 [`business-value.md`](business-value.md)。
